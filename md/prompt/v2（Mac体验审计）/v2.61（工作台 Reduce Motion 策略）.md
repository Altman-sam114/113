# v2.61 工作台 Reduce Motion 策略

## 版本号与分配依据

- 版本号：v2.61。
- 分配依据：`update_log.md` 最新正式轮次为 v2.60，本轮继续推进 Agent X 的 UI、Mac 与 iPad 全面优化目标。
- 基线：`origin/main` v2.60 已通过两轮 GitHub Actions artifact 验收，当前 XCTest 为 103 项。

## 背景

`LocalGemma/ContentView.swift` 有 10 处显式 `withAnimation`，覆盖工作区跳转、主题切换、compact/regular 导航、聊天自动滚动、导出复制反馈和模型选择。当前没有读取 `accessibilityReduceMotion`，因此 Mac Catalyst 和 iPadOS 开启“减弱动态效果”后，整页分页、连续聊天滚动和模型详情重排仍执行 spring/ease-out 空间动画。

三路只读审计将该问题列为 P1。审计同时发现根窗口跨 700pt 会在 portrait/landscape 两套结构间重建工作区；该结构身份问题需要独立设计和更强 UI 验证，列为后续轮次，不混入 v2.61。

## 目标

- 新增 `AppMotionEffect` 五类效果：`workspaceNavigation`、`transcriptAutoScroll`、`modelSelection`、`themeChange`、`copyConfirmation`。
- 新增纯策略 `AppMotionAccessibilityPolicy.animation(_:for:reduceMotion:)`，只决定动画，不接管业务动作。
- `workspaceNavigation`、`transcriptAutoScroll`、`modelSelection` 标记为大范围空间运动；Reduce Motion 开启时返回 `nil`。
- `themeChange`、`copyConfirmation` 标记为局部反馈；Reduce Motion 开启时返回 `.easeOut(duration: 0.12)`。
- Reduce Motion 关闭时原样返回调用点传入的动画，不统一或改写原 spring/ease-out 参数。
- `ContentView`、`ChatTranscript`、`ExportSessionView`、`ModelLibraryView` 分别读取 `accessibilityReduceMotion`。
- 10 处显式 `withAnimation` 全部接入共享策略，动作闭包继续只执行一次。
- 新增 XCTest，测试总数从 103 增至 104。

## 非目标

- 不重构 700pt 根窗口 portrait/landscape 双结构，不解决跨断点时 composer、聊天记录或会话栏滚动身份问题。
- 不修改 `WorkspaceLayoutMode`、v2.60 的 860pt 聊天 pane 分栏策略或 `SessionBar` 轴向结构。
- 不新增 UI Test target，不修改 `.page` TabView 手势，不重做主题颜色、圆角、阴影或密度。
- 不改变工作区/会话 command menu、composer focus、聊天滚动目标、剪贴板写入、模型选择、artifact、runtime、辅助语义、44pt 触控目标或 verified 门禁。
- 不下载模型权重，不接云端推理，不创建原生 macOS target。

## 实现步骤

1. 新增 `AppMotionEffect: CaseIterable, Hashable` 和可测试的 `isLargeSpatial` 分类。
2. 新增 `AppMotionAccessibilityPolicy`，定义 0.12s reduced-feedback 时长。
3. 正常模式返回调用点传入动画；Reduce Motion 下空间运动返回 `nil`，局部反馈返回短 ease-out。
4. 在四个拥有动画入口的 View 读取系统 Reduce Motion 环境值。
5. 替换全部 10 处 `withAnimation` 参数，不移动或复制原动作闭包。
6. 新增 `testAppMotionAccessibilityPolicyRespectsReduceMotion`，锁住五类 effect 完整集合、互斥分类和两种设置下的 nil/non-nil 行为。
7. 同步 AGENTS、README、测试规范、核心流程、流程图和 update log。

## 测试要求

- `AppMotionEffect.allCases` 必须等于三类空间运动与两类局部反馈的并集，两组互斥。
- 三类空间运动在 Reduce Motion 开启时为 `nil`、关闭时非空。
- 两类局部反馈在两种设置下均非空，reduced-feedback 时长常量为 0.12s。
- 正常模式由策略直接返回调用点传入动画，不能把所有入口统一成单一曲线。
- 现有 103 项测试不得删除、跳过或弱化；完成后总数为 104。
