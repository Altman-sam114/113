# v2.59 工作台视觉层级系统

## 版本号与分配依据

- 版本号：v2.59。
- 分配依据：`update_log.md` 最新正式轮次为 v2.58，本轮在 Agent X “全面优化重构 UI、Mac 与 iPad 体验”总目标下继续递增。

## 背景

v2.45-v2.58 已完成主要文本 Dynamic Type 与触控目标收敛，但视觉层级仍停留在原型阶段：紧凑工作区 tab 和宽屏 sidebar 每一项都是独立圆角卡片，选中项使用整块高饱和 accent；共享 `panelStyle` 固定使用 18pt 圆角和 `Color.primary` 描边，不能读取当前主题。Mac Catalyst 和 iPad 宽屏因此缺少安静、精确、统一的工作台层级。

三路只读子 agent 审计后，本轮选择共享 panel 与工作区导航轨道作为首个可感知视觉重构切片。聊天页双 sidebar 宽度行为留给下一轮独立处理。

## 目标

- 新增 `WorkbenchVisualStylePolicy`，集中定义控制/面板圆角、导航间距、选中指示器、描边、padding 和亮暗主题透明度。
- 紧凑工作区 tab 改为共享导航托盘，未选项透明，选中项使用低饱和表面和底部细指示条。
- Mac/iPad 宽屏 sidebar 改为低噪声导航轨道，选中项使用细左侧指示条、语义色 icon tile 和轻量表面，不再整块反色。
- `panelStyle` 改为 environment-aware modifier，统一主题表面、8pt 精密圆角、hairline 描边和 14pt padding。
- 保留工作区快捷键、command menu、`selectedTab`、composer focus、44pt 触控目标、辅助语义、业务状态和 verified 门禁。
- 新增 XCTest 锁住视觉层级常量与选择指示规则。

## 非目标

- 不改变 `WorkspaceLayoutMode`、sidebar 宽度或聊天页内部会话栏断点。
- 不重做 Header、模型胶囊、状态 badge、部署按钮或文件按钮颜色系统。
- 不改变模型选择、部署、扫描、导入、卸载、会话、生成、导出或 optimizer 状态流。
- 不下载模型权重，不接入云端推理，不绕过 artifact verified 门禁，不创建原生 macOS target。

## 当前架构依据

- `LocalGemma/ContentView.swift`
  - `tabPicker` 是 iPhone/窄容器的工作区导航入口。
  - `sidebarTabPicker` 是 iPad/Mac 大屏工作区导航入口。
  - `panelStyle` 被多个工作区共享，是跨页面视觉层级的最小高收益入口。
  - `AppThemePalette` 已提供 accent、surface、recessedSurface、border 等语义色。
- `LocalGemmaTests/LocalGemmaTests.swift`
  - 已有工作区导航 44pt、辅助语义和 sidebar 文本策略测试。
  - 本轮新增工作台视觉层级策略测试，测试函数数从 101 增至 102。

## 实现步骤

1. 新增 `WorkbenchVisualStylePolicy`，定义 panel/control/icon 圆角、导航 spacing/inset、sidebar icon tile、compact/sidebar 指示器、描边和主题透明度。
2. `tabPicker` 使用共享 material 托盘，选中项低饱和填充并显示底部 indicator，未选项不再各自描边成卡片。
3. `sidebarTabPicker` 使用 4pt 轨道间距、30pt icon tile、3pt 左侧 indicator、低饱和选中表面和非反色文本。
4. landscape sidebar 使用主题 recessedSurface tint 与 material 分层，保留 hairline 分隔线。
5. 新增 `WorkbenchPanelModifier`，让 `panelStyle(border:)` 读取 `appTheme` 并统一 panel 几何和表面。
6. 新增 `testWorkbenchVisualStylePolicyDefinesNavigationAndPanelHierarchy`。
7. 同步 README、`md/test/test.md`、`md/flow/flow.md`、`md/flow/flowchart.md`、`AGENTS.md` 和 `update_log.md`。
