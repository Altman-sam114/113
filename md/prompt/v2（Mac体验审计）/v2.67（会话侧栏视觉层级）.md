# v2.67 会话侧栏视觉层级

## 版本号与分配依据

- 版本号：v2.67。
- 分配依据：v2.66 最终 commit `05fadfd` 对应 GitHub Actions run `30194942000` 已完成云端验收并 PASS。

## 背景

并发只读审计确认，推理页竖向会话侧栏仍使用高饱和 accent 胶囊和反色文字表达选中状态。该侧栏在 Mac Catalyst 与 iPad 宽屏分栏中持续可见，选中会话因此容易被误读为主操作按钮，并与同一界面的“新建会话”和发送按钮争夺视觉注意力。全局工作区侧栏已经采用低饱和选中表面、primary text、8pt 圆角和左侧指示条，竖向会话列表尚未接入这套低噪声工作台视觉层级。

## 目标

- 新增纯值 `SessionChipVisualStylePolicy`，只调整 `.vertical` 会话 chip 的视觉计划。
- 竖向选中行使用 8pt 圆角矩形、低饱和 selected surface、`theme.primaryText`、3pt 左侧 accent 指示条、8pt 指示条垂直 inset 和 1pt 主题 hairline border。
- 竖向未选中行不显示选中指示条，并保持克制的透明或轻量表面。
- 复用 `WorkbenchVisualStylePolicy.selectedSurfaceOpacity` 等既有视觉层级常量，避免建立第二套高亮语言。
- `.horizontal` 会话 chip 保持既有 accent 胶囊和既有文字表现，避免扩大紧凑布局回归面。
- 新增 `testSessionChipVisualStylePolicyAlignsWideSidebarHierarchy`，完整 XCTest 数量由 111 增至 112。

## 非目标

- 不改变横向会话栏的胶囊视觉、布局、滚动或紧凑设备体验。
- 不改变会话选择、删除、禁用原因、44pt 触控目标、Dynamic Type、辅助语义、Voice Control、composer focus、会话 command menu、导出或状态流。
- 不改变聊天记录阅读轨道、气泡宽度、自动滚动、模型文件、runtime 或 verified 门禁。
- 不下载模型权重，不接云端推理，不新增原生 macOS target。

## 实现与验证要求

1. `SessionChipVisualStylePolicy` 必须以纯值计划锁住竖向样式的 8pt row corner radius、3pt indicator width、8pt indicator vertical inset 和 1pt border width。
2. 竖向选中计划必须使用低饱和 selected surface、primary text、左侧 accent 指示条和主题感知 hairline；不得继续使用整行高饱和 accent 填充或反色文字。
3. 竖向未选中计划不得显示左侧选中指示条；其表面不得与选中态或主操作按钮争夺层级。
4. 横向计划必须保持既有胶囊圆角、高饱和 accent 选中表面及既有文字对比策略，不得被竖向样式重构改变。
5. 生产 `SessionChip` 只在 `.vertical` 接入新计划，保留选择按钮、删除按钮、44pt 命中区域、两行语义标题、辅助语义和稳定 identifier。
6. 新增 `testSessionChipVisualStylePolicyAlignsWideSidebarHierarchy`，覆盖竖向选中/未选中计划、8/3/8/1pt 常量、低饱和表面、primary text、指示条开关，以及横向计划保持既有表现。
7. 对生产 `SessionChip` 在 240pt、310pt 宽度，亮/暗主题及 `.accessibility3` 下执行非空、有限尺寸 `ImageRenderer` 烟测；不使用脆弱的逐像素快照断言。
8. 只通过 GitHub Actions 执行 iOS build、Mac Catalyst build、LogicSmoke 和完整 112 项 XCTest；不运行本地 Xcode、Simulator、Mac build 或截图。
9. 同步 `AGENTS.md`、`README.md`、`md/flow/flow.md`、`md/flow/flowchart.md`、`md/test/test.md` 和 `update_log.md`。
