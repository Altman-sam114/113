# v2.74 会话侧栏 hover 反馈

## 版本依据

- 版本：`v2.74`。
- 基线：v2.73 `0a8dbce` 已通过 GitHub Actions run `31292379905`；记录提交 `db7912d` 的云端 run `31293060004` 也已成功。
- 本轮目标来自 Mac/iPad UI 审计：提升大屏竖向会话侧栏未选中行的 pointer hover 可发现性，继续保持本地状态、辅助语义和触控目标不变。

## 背景与目标

Mac Catalyst 与 iPad pointer 用户在 240...310pt 竖向会话侧栏中移动指针时，未选中行与基础侧栏表面区分度有限。本轮新增独立纯值 `SessionChipHoverStylePolicy`，只为竖向、未选中且当前被 hover 的行提供低透明度 accent 表面。

目标：

1. 让 Mac Catalyst/iPad pointer hover 有即时、克制的视觉反馈。
2. 亮色 hover opacity 为 `0.06`，暗色为 `0.10`；两者均低于既有选中表面。
3. 保持现有 `SessionChipVisualStylePolicy`、选中指示条、背景圆角、hairline、标题/metadata、删除按钮与布局尺寸不变。
4. 用纯值 policy 锁住组合边界和生产渲染尺寸，避免依赖像素 alpha 或私有 SwiftUI 层级。

## 非目标

- 不改变横向 title-only capsule。
- 不改变选中竖向行，即使指针位于选中行也不叠加 hover surface。
- 不增加 focus、selection、session、composer、剪贴板、runtime、模型文件或持久化状态。
- 不新增动画、`withAnimation`、`AppMotionEffect` case、Timer、task 或 reduce-motion 分支。
- 不增加辅助技术元素、label/value/hint/input label/trait/identifier，不把装饰层暴露给 VoiceOver/Voice Control。
- 不改变 `SessionChipActionLayoutPolicy` 的选择/删除 44pt 触控目标，不吞掉删除按钮区域命中。
- 不修改用户保留的 `LocalGemma.xcodeproj/project.pbxproj`。

## 架构依据

- `LocalGemma/ContentView.swift`：`SessionBar` 在 `.vertical` 中渲染真实 `SessionChip`；`SessionChipVisualStylePolicy` 已控制选中/未选中形状与层级；`SessionChipSidebarMetadataPolicy` 已控制 v2.73 消息数/摘要。
- `LocalGemmaTests/LocalGemmaTests.swift`：已有 `SessionChip` policy、Dynamic Type、亮暗主题、240/310pt 与生产 `ImageRenderer` 契约。
- `md/flow/flow.md` 与 `md/flow/flowchart.md`：SessionBar -> SessionChip 的本地只读 UI 数据流；hover 只能是 view 装饰，不得进入 `InferenceEngine` 或 `ChatSession`。

## 实现要求

1. 在现有 `SessionChipVisualStylePolicy` 附近新增 `SessionChipHoverStylePolicy`，建议提供：
   - `usesHoverSurface(layout:isSelected:isHovered:) -> Bool`。
   - `hoverSurfaceOpacity(isDark:) -> Double`，亮色 `0.06`，暗色 `0.10`。
   - 常量应为纯值、可直接由 XCTest 读取；非法条件不应产生 hover。
2. 在 `SessionChip` 增加局部 `@State` hover 布尔值，并在整个 chip 行使用 `.onHover`；使用 `contentShape(Rectangle())` 覆盖 padding 与删除按钮所在区域。
3. hover 只在 `.vertical && !isActive && isHovered` 时成立；`.horizontal`、选中行和非 hover 均返回 false。
4. 将 accent hover fill 作为既有竖向背景内部的装饰叠加，保留未选中 `theme.chipSurface.opacity(0.34)`、选中背景、边框和左侧 indicator。装饰层应 `.allowsHitTesting(false)` 与 `.accessibilityHidden(true)`。
5. `.onHover` 不得包住/替换两个既有 Button，不得改变选择/删除闭包、disabled 语义、accessibility metadata、identifier、frame、padding、Dynamic Type 或 `SessionChipSidebarMetadataPolicy` 输出。
6. 不使用 `.hoverEffect` 取代自定义 policy；工程最低 iOS 17，`.onHover` 可用于 Mac Catalyst/iPad pointer，iPhone 无 pointer 时保持无 hover。

## 测试要求

新增 `testSessionChipHoverStylePolicyRestrictsPointerFeedback` 或同等清晰名称，覆盖：

- `.vertical`/`.horizontal` × selected/unselected × hovered/non-hovered 的完整组合。
- 只有 vertical + unselected + hovered 为 true；横向和选中始终 false。
- light opacity `0.06`、dark opacity `0.10`，均小于既有选中表面 opacity；不新增 motion case。
- 真实 `SessionChip` `ImageRenderer`：240/310pt、亮/暗主题、`.large`/`.accessibility3`、选中/未选中、hover false/true；断言图像非 nil、宽度稳定、合理高度，不做像素 alpha 或私有宿主层级断言。
- horizontal sentinel 在 hover true 下保持 title-only 几何；选择与删除动作仍是同级可达入口。
- 测试不要求 XCTest 伪造真实 pointer enter/exit；真实 Mac Catalyst/iPad pointer 行为作为手工验证边界记录。

既有 118 项测试必须保持通过，新增后源码测试函数应为 119。保留 v2.73 摘要、44pt、辅助语义、Reduce Motion、runtime verified 门禁测试。
