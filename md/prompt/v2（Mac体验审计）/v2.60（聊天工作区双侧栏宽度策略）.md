# v2.60 聊天工作区双侧栏宽度策略

## 版本号与分配依据

- 版本号：v2.60。
- 分配依据：`update_log.md` 最新正式轮次为 v2.59，本轮继续推进 Agent X 的 UI、Mac 与 iPad 全面优化目标。

## 背景

`ContentView` 已按总窗口宽度决定全局工作区 sidebar，`ChatWorkspace` 随后又对扣除全局 sidebar 后的剩余 pane 复用 `WorkspaceLayoutMode` 的 700pt 断点。根窗口从 1029pt 增至 1030pt 时，聊天 pane 会从约 700pt 的横向会话栏布局切成 240pt 竖向会话栏，主聊天区反而骤降到约 460pt。现有 `SessionSidebarLayoutPolicy` 只限制会话栏自身宽度，没有保证聊天主区最小可读宽度。

三路只读子 agent 审计一致将该问题列为 P1，并指出现有测试使用完整窗口宽度验证会话栏，未覆盖真实的“先扣全局 sidebar，再决定会话 sidebar”组合路径。

## 目标

- 新增 `ChatWorkspacePaneMode`、`ChatWorkspacePaneLayout` 和 `ChatWorkspacePaneLayoutPolicy`。
- policy 直接读取 `ChatWorkspace` 的真实 pane 尺寸，不再复用全局 `WorkspaceLayoutMode`。
- pane 小于 860pt 时使用顶部横向会话栏；达到 split 条件后才显示竖向会话栏。
- split 模式始终为聊天主区保留至少 620pt，并让会话栏保持既有 240...310pt 范围。
- `SessionSidebarLayoutPolicy` 新增容器首选宽度入口，保留现有 API 与历史测试。
- `ChatWorkspace` 使用 `AnyLayout` 在 HStack/VStack 之间切换同一组 session/chat 子视图，避免因两套 `if/else` 子树放大 Mac resize 时的输入焦点和滚动位置重建风险。
- 新增 XCTest 覆盖无效宽度、策略临界值、真实 iPad/Mac 根窗口组合和宽度守恒。

## 非目标

- 不改变全局 `WorkspaceLayoutMode` 或工作区 sidebar 宽度。
- 不重做 `SessionBar`、`SessionChip`、聊天气泡、composer 或导出弹层视觉。
- 不新增纯图标会话 rail，不改变会话标题和删除动作语义。
- 不改变会话创建/选择/删除/导出、composer focus、command menu、44pt 触控目标或辅助语义。
- 不下载模型权重，不接云端推理，不绕过 artifact verified 门禁，不创建原生 macOS target。

## 当前架构依据

- `ContentView.landscapeLayout` 先为全局 sidebar 分配宽度。
- `ChatWorkspace` 的 `GeometryReader` 收到扣除全局 sidebar 后的真实 pane 尺寸。
- `SessionSidebarLayoutPolicy` 定义会话栏 240...310pt 和 0.28 首选比例。
- `SessionBarLayout.horizontal` / `.vertical` 已承载同一组会话动作和辅助语义。

## 实现步骤

1. 为 `SessionSidebarLayoutPolicy` 增加 `preferredWidth(forContainerWidth:)`，处理非有限或非正宽度并复用既有 clamp。
2. 新增 `ChatWorkspacePaneLayoutPolicy`，定义 620pt 聊天主区下限和派生的 860pt split 最小容器宽度。
3. `resolve(for:)` 对无效/窄 pane 返回 `.stacked`，session sidebar 宽度为 0；对足够宽 pane 返回 `.split`，并将首选会话栏宽度限制到不侵占 620pt 聊天主区。
4. `ChatWorkspace` 删除内层 `WorkspaceLayoutMode.resolve`，改用 pane policy。
5. 用 `AnyLayout(HStackLayout/VStackLayout)` 复用单一 `SessionBar` 和 `chatSurface` 子树，并根据 mode 应用现有 padding、material 和 hairline。
6. 新增 `testChatWorkspacePaneLayoutPolicyCoordinatesGlobalAndSessionSidebars`，测试函数总数从 102 增至 103。
7. 同步 README、`md/test/test.md`、`md/flow/flow.md`、`md/flow/flowchart.md`、`AGENTS.md` 和 `update_log.md`。

## 关键验收场景

- 无效、零和负宽度安全回退 `.stacked`。
- pane 859.99pt 使用横向会话栏；860pt 可进入 split，聊天区保持 620pt。
- 根窗口 1024pt、1030pt、1180pt 在扣除全局 sidebar 后使用 stacked，不再出现 460...562pt 双侧栏聊天区。
- 根窗口 1280pt、1366pt 在剩余 pane 足够宽时使用 split，session sidebar 位于 240...310pt，聊天区至少 620pt。
- 每个组合满足 `workspace sidebar + session sidebar + chat surface <= root window width`。
