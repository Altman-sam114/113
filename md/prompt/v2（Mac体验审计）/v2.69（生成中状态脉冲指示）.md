## 背景与目标

`ChatBubble`（`LocalGemma/ContentView.swift` 第 4239 行起）当前在第 4265 行用同一个 `Text` 渲染正文与生成占位：`message.text.isEmpty ? "正在生成..." : message.text`。静态省略号无法传达"本地模型正在写入"的进行感，与顶部模型胶囊、composer 生成态描边的工作台质感不匹配。v2.69 把空文本占位替换为专用生成指示视图：

- 语义字体文本「正在生成」（沿用 `.body.weight(.medium)` 语义字体，前景色 `theme.secondaryText`），尾随 3 个 `theme.accent` 圆点。
- 圆点直径 5pt、间距 4pt，opacity 在 0.35 与 1.0 之间以 `easeInOut` 0.9 秒 `repeatForever(autoreverses: true)` 脉冲，逐点相位延迟 0.15 秒，形成从左到右的呼吸波。
- Reduce Motion：`ChatBubble` 直接读 `@Environment(\.accessibilityReduceMotion)`（项目已有多处先例，如第 3879 行 `ChatTranscript`），开启时不启动任何 repeatForever 动画，3 个圆点使用静态梯度 opacity 0.35 / 0.65 / 1.0，保持"进行中"的视觉语义但零动效。
- 运行时切换：动画启停必须响应系统 Reduce Motion 的运行时变化，推荐用 `.task(id: reduceMotion)`（`ComposerBar` 第 5023 行 `.task(id: ComposerFocusTaskID(...))` 是既有先例）在标识变化时取消旧任务、重置动画相位 `@State`，再按 `isAnimated(reduceMotion:)` 决定是否用 `withAnimation` 启动脉冲；也可用等价的 `id` 重建 + `onAppear` 机制，但不得引入 Timer 泄漏或在 Reduce Motion 开启后仍残留脉冲。

新增纯值 `GenerationIndicatorStylePolicy`（枚举 + 静态常量/函数，风格对齐 `ChatBubbleTextLayoutPolicy` 等既有 policy）：

- `dotCount = 3`、`dotDiameter: CGFloat = 5`、`dotSpacing: CGFloat = 4`。
- `minOpacity = 0.35`、`maxOpacity = 1.0`、`pulseDuration = 0.9`、`phaseDelay = 0.15`。
- `isAnimated(reduceMotion:) -> Bool`：`reduceMotion == false` 时为 true，开启时为 false。
- `staticOpacity(forDotIndex:) -> Double`：Reduce Motion 静态梯度，index 0/1/2 返回 0.35 / 0.65 / 1.0，必须随 index 单调递增，首尾分别等于 `minOpacity` 和 `maxOpacity`。

`ChatBubble` 中的视图从策略读取全部常量，不得在视图内散落魔法数字。

## 非目标与回归边界

- 硬红线一：绝不给 `AppMotionEffect`（`ContentView.swift` 第 114-130 行）新增 case。`testAppMotionAccessibilityPolicyRespectsReduceMotion` 用手写的 largeSpatial/localFeedback 两个集合断言 `union == Set(AppMotionEffect.allCases)`，allCases 必须恰为现有 5 个。持续脉冲动效走独立的 `GenerationIndicatorStylePolicy` + 视图直接读 environment，不复用 `AppMotionAccessibilityPolicy.animation`。
- 硬红线二：不改任何 `*AccessibilityMetadata` 字符串。气泡整体是 `accessibilityElement(children: .ignore)`（第 4307 行），空文本朗读文案由 `ChatMessageAccessibilityMetadata.spokenText`（第 1947 行，空 assistant 返回「正在生成，本地模型正在写入模拟输出」）锁定；本轮纯视觉替换，label/value/hint/inputLabels/identifier 及其测试全部不得触碰。

- iOS 17 兼容（deployment target 17.0），Mac Catalyst 必须同等工作；不使用 iOS 18-only API、私有 API、UIKit 层级探查或 Timer 常驻。
- 不下载模型权重、不接云端推理、不新增原生 macOS target、不做无关重构。

## 风险与禁止项

- repeatForever 动画若绑定在被 `LazyVStack` 回收重建的视图上，相位状态会重置；这是可接受的占位行为，但不得为此引入全局 Timer、DisplayLink 或第二套滚动/消息状态。
- Reduce Motion 运行时开启后若脉冲残留即为 bug；`.task(id:)` 取消路径必须落到静态梯度。
- 禁止下载模型权重、禁止云端推理、禁止绕过 artifact verified 门禁、禁止伪造测试结果、禁止验收旧 run/旧 artifact、禁止编辑用户的 `project.pbxproj`、禁止给 `AppMotionEffect` 加 case、禁止改任何 `*AccessibilityMetadata` 文案。
