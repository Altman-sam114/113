### 体验问题

- 在 iPad split view、Mac Catalyst 窄窗口和较大 Dynamic Type 下，固定 13/11/15pt 字号不会随系统语义字号增长；运行策略标题和说明的阅读层级与其他已适配的指标卡、设置偏好行不一致。
- 当前行有两行副标题限制，但没有 `fixedSize(horizontal: false, vertical: true)` 或语义字体保证；文字可能被压缩到不可读，且行高度只依赖固定字号。
- 这是局部 UI 排版问题，适合用纯值常量和公开 `ImageRenderer` 生产渲染矩阵锁定，不涉及模型文件、runtime、网络、会话或持久化。

## 目标

1. 新增 `OptimizationToggleTextLayoutPolicy`，集中定义运行策略小节标题、行标题和副标题的 Dynamic Type 排版契约。
2. `OptimizationToggleGrid` 与 `OptimizationToggleRow` 使用 SwiftUI 语义字体，不再使用本轮范围内的固定 `system(size:)` 文字字号或 `minimumScaleFactor`。
3. 小节标题、行标题和副标题允许垂直增长；至少保留标题两行、副标题两行的稳定上限，避免 iPad/Mac 窄宽度下横向挤压文字。
4. 设置页与优化 dashboard 必须继续复用同一个 `OptimizationToggleGrid`、同一个 `OptimizationToggleRow` 和同一个 text policy，不得在两个调用点复制排版分支。
5. 保持 `OptimizationToggleRowLayoutPolicy.rowMinHeight >= 44pt`、既有单列/双列网格断点、开关顺序、enabled 状态、点击闭包、辅助语义、Reduce Motion 和 verified 门禁完全不变。
6. 普通字号的视觉层级保持接近当前实现：小节标题仍为粗体，行标题强于副标题，副标题仍为次级文字；改变只应来自语义字体随 Dynamic Type 的合法增长和自然高度。

## 建议纯值 API

Agent B 可以使用同等清晰的命名，但生产 View 和 XCTest 必须共享同一 policy，不能在 View 内复制常量：

```swift
enum OptimizationToggleTextLayoutPolicy {
    static let gridTitleLineLimit = 2
    static let rowTitleLineLimit = 2
    static let subtitleLineLimit = 2
    static let rowVerticalSpacing: CGFloat = 3
    static let subtitleLineSpacing: CGFloat = 2

    static var allowsMultilineGridTitle: Bool {
        gridTitleLineLimit > 1
    }

    static var allowsMultilineRowTitle: Bool {
        rowTitleLineLimit > 1
    }

    static var allowsMultilineSubtitle: Bool {
        subtitleLineLimit > 1
    }
}
```

实现约束：

1. API 必须是无状态纯值入口，只包含可测试的静态常量/计算属性；不得读取 `Environment`、`DeviceOptimizer`、主题、窗口尺寸或时间。
2. `gridTitleLineLimit`、`rowTitleLineLimit`、`subtitleLineLimit` 必须大于 1；建议均为 `2`，避免本轮引入不同的截断策略。
3. `rowVerticalSpacing` 应保留当前 `VStack(spacing: 3)` 视觉关系；`subtitleLineSpacing` 可为 `0...2`，必须在测试中锁定实际值，不能在调用点散落数字。
4. policy 不需要暴露 `Font`，生产代码直接使用公开语义字体，例如 `.headline.weight(.black/.bold)`、`.subheadline.weight(.medium)`；这样保持 policy 可 Equatable/数值断言，字体选择不进入状态层。
5. 使用 `lineLimit` 与 `fixedSize(horizontal: false, vertical: true)` 允许垂直增长。不得使用 `minimumScaleFactor`、`allowsTightening`、固定 frame 高度或把文本改成图片。
