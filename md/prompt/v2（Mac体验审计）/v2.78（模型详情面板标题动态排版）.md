## 建议纯值 API

Agent B 可以使用同等清晰的命名，但生产 View 和 XCTest 必须共享同一 policy，不得在 View 内复制数字：

~~~
enum ModelDetailPanelTextLayoutPolicy {
    static let titleLineLimit = 2
    static let titleLineSpacing: CGFloat = 1
    static let titleContentSpacing: CGFloat = 12

    static var allowsMultilineTitle: Bool {
        titleLineLimit > 1
    }

    static var usesSemanticTitleFont: Bool {
        true
    }
}
~~~

实现约束：

1. API 必须是可重复读取的静态纯值入口，只含 CGFloat、Int、Bool 或无状态计算属性；不得读取 Environment、Dynamic Type、主题、窗口尺寸、模型、artifact、会话、剪贴板、时间或 runtime。

4. DetailPanel 应直接使用 ModelDetailPanelTextLayoutPolicy.titleLineLimit、.titleLineSpacing 和 .titleContentSpacing；不得在 View 中重新写同一数字。标题要加 .fixedSize(horizontal: false, vertical: true) 或等价公开布局约束以允许垂直增长，但不得固定高度。
5. titleLineLimit 只限制未来极长本地化标题最多两行，不得给详情正文、DetailRow 或 AdviceRow 增加新的 line limit；当前三个标题不应被截断。
