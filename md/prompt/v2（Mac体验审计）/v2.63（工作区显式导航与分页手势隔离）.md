# v2.63 Agent B 提示词：工作区显式导航与分页手势隔离

## 版本依据

基于 `origin/main` 的 v2.62 云端验收基线继续递增为 v2.63。本轮是 Agent X 总目标中针对 Mac Catalyst 与 iPad 工作区手势可靠性的独立小目标。

## 背景与目标

v2.62 已用 `WorkspaceRootShell` 保持根断点两侧的 content 结构身份，但共享 content 仍是 page-style `TabView`。Mac 触控板和 iPad 横向拖动可能绕过显式导航切换工作区，并与聊天页横向会话列表竞争。

本轮以四个固定同序页面槽位替换 page-style 分页容器。只有当前页可见、可命中、启用并对辅助技术可达；隐藏页保留 SwiftUI 状态身份但不能响应控件、快捷键或辅助访问。工作区只由顶部/侧栏、系统菜单、`Command+1...4` 和既有状态路由切换。

## 非目标

- 不重构聊天阅读轨道、模型胶囊、生成状态或其他视觉系统。
- 不引入私有 API、透明手势拦截层、全局 `.scrollDisabled`、第三方依赖或新 UI Test target。
- 不下载模型权重，不接云端推理，不发送 prompt/会话，不绕过 artifact `verified` 门禁。
- 不创建原生 macOS target。

## 架构依据与实现

先读 `AGENTS.md`、`update_log.md`、`md/flow/flow.md`、`md/flow/flowchart.md`、`md/test/test.md`、`README.md` 和 `md/prompt/README.md`，再读 `LocalGemma/ContentView.swift` 与 `LocalGemmaTests/LocalGemmaTests.swift`。

在 `ContentView.swift` 增加纯值 `WorkspacePagePresentation`、`WorkspacePagesInteractionPolicy` 和泛型生产 `WorkspacePagesShell`。宿主使用同序 `ZStack` 固定持有 `.chat/.models/.prompts/.settings` 四页，对每页统一应用 frame、opacity、hit testing、disabled、accessibility hidden 和 z-index。生产 `workspacePages` 每个 workspace 只构造一次，移除 page-style `TabView`。

保留 `selectedTab`、`workspaceSelection`、`selectWorkspace`、focused command route、主题、模型文件与 runtime 状态流。composer focus 必须额外受聊天活动态约束：离开聊天页取消待处理聚焦并清空隐藏输入框的 `@FocusState`，重新进入仍使用既有 request route。
