# v2.64 模型胶囊窄侧栏响应式布局

## 版本号与分配依据

- 版本号：v2.64。
- 分配依据：v2.63 已完成 `4534211` 实现、`cbf9776` 验收记录和最终 run `30191068195` 云端闭环。

## 背景

v2.63 iPad Pro 13-inch 截图显示 regular sidebar 中 `ModelCapsule` 的模型名被压成多段并截断。三路并发审计确认：侧栏扣除 18pt 外边距与胶囊 12pt padding 后空间有限，当前头部仍固定横排 42pt 图标、模型名、两枚徽章和 readiness ring，三个指标也始终横排；`ReadinessRing` 外层声明 54pt、内部固定 66pt 还会额外侵占布局。

## 目标

- 新增纯值 `ModelCapsuleLayoutPolicy`，根据胶囊外框可用宽度、`WorkspaceLayoutMode` 和 Accessibility Dynamic Type 生成头部 presentation 与 1/2/3 列指标计划。
- sidebar 使用堆叠头部；窄 top header 同样回退堆叠，宽 top header 保留横向概要。
- 2 列指标时速度/内存并排，后端与 artifact 状态跨整行；`.xxxLarge` 及以上文字统一单列。
- 让 `ReadinessRing` 的实际渲染直径与调用计划一致。
- 新增策略边界与生产 `ImageRenderer` 测试，108 -> 109。

## 非目标

- 不改变 `ModelCapsuleAccessibilityMetadata`、SIM/REAL 或安装状态语义。
- 不改变主题、工作区导航、模型文件、runtime、生成状态或 verified 门禁。
- 不下载模型权重，不接云端推理，不新增原生 macOS target。

## 实现与验证要求

1. 调用侧使用真实 chrome 宽度扣除共享 18pt 外边距，不创建第二套根窗口断点。
2. 非法宽度和 `.xxxLarge` 及以上文字返回 stacked + 1 列；portrait 最多 3 列，compact/regular sidebar 最多 2 列。
3. 测试锁住 248pt/436pt 精确阈值、108/132pt 两列/三列最小指标宽度、NaN/Infinity/负值，以及真实 sidebar 可用宽度。
4. 本地至少运行 build-for-testing、定向 iPad XCTest、实际 App 截图与 Mac Catalyst build/run；完整 XCTest 由 push 后 GitHub Actions 与 Agent C artifact 验收。
5. 同步 `AGENTS.md`、`README.md`、`md/flow/flow.md`、`md/flow/flowchart.md`、`md/test/test.md` 和 `update_log.md`。
