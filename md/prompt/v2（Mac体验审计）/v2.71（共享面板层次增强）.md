## 背景与目标

`WorkbenchVisualStylePolicy`（`LocalGemma/ContentView.swift` 约第 80 行）已统一共享 panel 的 8pt 圆角、14pt 内边距、1pt hairline、主题表面 tint；`WorkbenchPanelModifier`（约第 7113 行）通过 material + theme surface + 最外层 border 实现 `panelStyle(border:)`。当前 panel 与背景主要依靠表面色和单层描边区分，在 iPad/Mac Catalyst 大画布、浅色背景和连续设置面板中纵深偏平。

v2.71 在现有共享 modifier 内增加主题感知的内高光和 contact + ambient 两层阴影，不修改调用 API，不新增 panel variant：

1. 内高光：
   - `panelInnerHighlightWidth: CGFloat = 0.5`。
   - `panelInnerHighlightOpacity(isDark:)`：暗色 `0.18`，亮色 `0.48`。
   - 使用从 `.topLeading` 到 `.bottomTrailing` 的白色到透明 `LinearGradient` 描边，营造克制的内缘高光。
   - 高光 shape 向内 inset 现有 `hairlineWidth`，并在最外层 `border ?? theme.border` 之前绘制，不能覆盖或冲淡 accent border。
2. 接触阴影：
   - `panelContactShadowRadius: CGFloat = 1.5`。
   - `panelContactShadowY: CGFloat = 1`。
   - `panelContactShadowOpacity(isDark:)`：暗色 `0.28`，亮色 `0.10`。
3. 环境阴影：
   - `panelAmbientShadowRadius: CGFloat = 8`。
   - `panelAmbientShadowY: CGFloat = 3`。
   - `panelAmbientShadowOpacity(isDark:)`：暗色 `0.20`，亮色 `0.08`。
4. 两层阴影使用黑色或项目既有中性阴影基色，并只挂在 panel 背景 `RoundedRectangle` / 背景容器上；不得挂到 `content`，避免文字、图标和控件产生投影。
5. 内高光和阴影都是静态装饰。装饰层必须 `.allowsHitTesting(false)` 且 `.accessibilityHidden(true)`，不得增加动画、状态或辅助技术节点。

所有数字必须收敛进 `WorkbenchVisualStylePolicy`，生产 modifier 只读取 policy，不在视图内散落魔法数字。API 命名可做符合现有风格的微调，但数值、主题分支和层级关系不可改变。

## 非目标与回归边界

- 保持 `WorkbenchVisualStylePolicy.panelCornerRadius == 8`、`panelPadding == 14`、`hairlineWidth == 1`；不改变 control/icon 圆角、导航托盘、sidebar 轨道、选中指示器、panel tint 或其他既有常量。
- 保持 `panelStyle(border: Color? = nil) -> some View` 签名和 `WorkbenchPanelModifier(border:)` 调用方式不变；不引入 elevation enum、多个 panel variant、调用侧新参数或第二套 visual-style policy。
- 保持 material、theme surface tint 与最外层 `border ?? theme.border` 的现有语义。自定义 accent border 必须最后绘制，不能被内高光替代、混色或覆盖。
- 不添加 `padding`、`frame`、`offset`、布局 spacer、`clipShape`、`drawingGroup()`、`compositingGroup()`、额外 blur 或为阴影补偿空间；阴影不得改变 panel 的测量尺寸、滚动范围或 9 个调用点布局。
- 环境阴影固定为 radius 8 / y 3，不因 ScrollView 边缘可能裁切而增大半径或修改父容器 padding。只保留 contact 和 ambient 两层，控制 material 合成成本。
- 不形成 panel 套 panel，不修改页面内容顺序、宽屏断点、网格列数、Dynamic Type 文本策略、工作区布局、导航、模型选择/部署、模型文件操作、优化开关或壁纸状态流。
- 不改变任何 `*AccessibilityMetadata` 字符串、`.accessibilityElement` 结构、Voice Control 输入标签、稳定 identifier、44pt 触控目标、键盘快捷键、composer focus 或 focused command route。
- 不新增 `withAnimation`、`.animation(_:value:)`、transition、task 或 `AppMotionEffect` case；本轮是纯静态装饰，Reduce Motion 行为不变。
- 不改变 `ModelCatalog`、`ModelArtifactStore`、artifact validation、`InferenceEngine`、模拟 runtime、真实 runtime placeholder 或 verified artifact 门禁。
- iOS 17 与 Mac Catalyst 兼容；不使用 iOS 18-only API、私有 SwiftUI 层级、UIKit 宿主层级探查或像素颜色/alpha 采样。
- 不下载 Gemma 或其他模型权重，不接云端推理，不发送 prompt/会话到外部服务，不新增原生 macOS target，不做无关重构。

## 实现要求

- 在 `LocalGemma/ContentView.swift` 的现有 `WorkbenchVisualStylePolicy` 中加入全部内高光、contact shadow 和 ambient shadow 纯值常量/函数。
- 在现有 `WorkbenchPanelModifier` 内完成绘制：
  - 背景仍由 8pt continuous `RoundedRectangle` 的 `.ultraThinMaterial` 与主题 surface tint 组成。
  - contact 与 ambient shadow 只作用于背景 shape/container；x offset 保持 0。
  - 内高光用 inset 后的 continuous `RoundedRectangle` 渐变描边，宽度 0.5，亮/暗 opacity 从 policy 读取。
  - 最外层现有 border 最后绘制，line width 继续读取 `hairlineWidth`。
  - 所有装饰层禁用 hit testing 并从 accessibility tree 隐藏。
- `extension View.panelStyle(border:)` 一字不改；9 个调用点不需要编辑。如因格式化产生无语义调用点 diff，应撤掉这些无关改动。

## 风险与禁止项

- 阴影挂到 `content` 会让文字和控件产生投影，必须只挂背景 shape/container。
- 内高光晚于 accent border 绘制会冲淡状态边界；必须先画 inset 内高光，最后画既有 outer border。
- 为避免 ScrollView 裁切而增加 padding/frame 会改变布局契约；禁止补偿阴影空间。
- 给 panel 内 Picker、toggle row、badge、chip 或按钮再次加 `panelStyle` 会形成卡片嵌套；禁止新增第 10 个调用。
- 禁止使用像素 alpha/color、阴影边界像素、私有 SwiftUI/UIKit 层级作为测试 oracle；只锁纯策略值/关系和生产视图可渲染性。
- 禁止修改 8pt radius、14pt padding、1pt border、`panelStyle` API、9 个调用、页面布局、业务状态、辅助语义、44pt 触控目标、动画策略、runtime 或 verified 门禁。
- 禁止本地 Xcode build/test/Simulator/Catalyst，禁止伪造测试结果，禁止验收旧 run/artifact，禁止下载模型权重或接入云端推理，禁止编辑或提交用户的 `project.pbxproj`。
