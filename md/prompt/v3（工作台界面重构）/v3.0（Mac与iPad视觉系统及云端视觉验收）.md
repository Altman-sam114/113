日期：2026-09-26。当前正式实现为 v2.85；人工明确要求全面 UI 重构，因此升级主版本至 v3.0。保留已有未提交工程签名设置与 v2.x 提示词。

## 总目标与执行方式

Agent X 以可发布品质为方向，自行寻找 UI 问题并完成设计、实现、验收。本轮按人工要求由同一代理串行承担 A/B/C 工作，不创建子智能体。只在 GitHub Actions 云端编译、运行 LogicSmoke、XCTest、Simulator 和 Catalyst；本机只读写源码和执行静态检查。

## 架构依据与设计目标

依据 AGENTS.md、md/flow/flow.md、md/test/test.md、ContentView.swift 以及当前 CI：状态层及 verified gate 已具备测试；UI 集中在超过八千行文件，导航占宽、标题层级、背景和重复面板需要形成统一系统。

1. 提取主题/视觉基础与工作台 chrome，降低 ContentView 的职责密度；新增文件必须加入 app target。
2. 建立深墨色/浅瓷白主题、青绿强调色、清晰分层表面和统一图标/标题，重构 Mac/iPad 导航信息架构。
3. 改善侧栏空间效率、聊天起始引导、消息与输入区、模型/提示词/设置页的标题及操作层级；支持窄 split view、横屏与 Dynamic Type。
4. 为真实生产页面增加云端 iPhone/iPad 截图和可核验 visual manifest，避免把 ImageRenderer 尺寸通过等同于视觉验收。

## 状态与禁止项

保留同一 WorkspaceRootShell/WorkspacePagesShell 身份、四个固定页面槽位、隐藏页命中/辅助隔离、composer 同步焦点、会话快捷键、44pt、Reduce Motion、现有本地导出和壁纸路径。只有经测试明确替换的视觉契约可变化。禁止模型下载、云端推理、虚构性能、绕过 verified、宣称真实 runtime 或原生 macOS 已完成。
