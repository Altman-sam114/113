# 隐私说明

更新时间：2026-11-01。适用于当前 Local Gemma 本地工作台原型；本说明不代表真实模型推理、签名分发或商店审核已经完成。

## 当前能力与网络边界

- 默认回复来自模拟 runtime，不会实际完成改写、翻译或总结。
- App 不主动上传对话、草稿、壁纸或模型文件，不收集使用分析，不用于广告跟踪，不自动下载模型权重，也不接入云端推理。
- 仅已登记的 Gemma 3 1B GGUF 在手动导入并通过 `verified` 后支持本机文本推理；文件校验不保证设备内存足够或生成成功。其他模型仍为模拟预览，参考速度、内存和设备预算不是实测结果。
- 原生库使用文件身份/时间属性检测加载期间变更，并使用单调时间测量本地生成耗时；不用于设备识别、跟踪或上传。实际发布包须继续审核依赖的隐私 API。

## 本机存储

- 对话、当前选择和逐会话草稿保存在 App 本机目录；会话目录（包括修复保留的原件）标记为不参与系统备份。存储有大小和格式校验；读取失败时禁止静默覆盖原记录。卸载 App 会失去未导出的对话。
- 自定义壁纸由系统照片选择器提供，App 只处理所选图片，在本机压缩后保存；不会上传图片。壁纸和外观偏好保存在 AppStorage，仍可能进入系统备份。应用不提供图片、语音或漫画翻译功能。
- 用户手动选择的模型文件会复制到标记为不参与系统备份的 App 托管目录。导入、校验、卸载不修改 Files 中的原始文件；原件受用户所选存储位置的规则约束。
- 会话目录和新导入模型目录的排除标记设置失败时，操作会报错。对旧版本已存在的模型目录，扫描仅尝试迁移；系统拒绝设置时不能保证其已排除备份。归档损坏或超限时仍先尝试设置会话目录标记，再拒绝读取，不覆盖原字节。
- 系统备份、迁移和系统剪贴板同步受系统设置控制；排除会话与托管模型目录不等于关闭系统备份，不会替用户移除既有备份。App 不主动上传也不代表禁用系统跨设备能力。

## 用户主动分享

导出在本机生成 Markdown 文件，文件不可用时可分享文本。只有用户操作分享或复制后，内容才交给系统分享面板或剪贴板。用户选择的接收 App、浏览器、网站或系统服务的网络和隐私行为不由本 App 控制。项目支持链接不会自动附加对话、草稿、模型文件或诊断信息。

## 删除与修复

1. 在会话记录中删除并确认，移除相应的本机对话和草稿。
2. 在模型页卸载并确认，只删除 App 托管副本，不删除 Files 原件。
3. 恢复系统背景，移除 App 保存的自定义壁纸。
4. 读取失败时，只有明确选择“保留原件并修复”才重建记录；原件备份仍保留在不参与系统备份的会话目录。
5. 已导出文件、既有系统备份和接收 App 的副本需分别管理。移除 App 不会替你删除这些外部副本。会话与托管模型按上述策略排除备份（旧目录迁移存在所述例外），卸载或更换设备前请自行导出需要保留的对话，并保留模型原件；不要依赖系统备份恢复它们。
