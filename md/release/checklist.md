# 发布前检查表

更新时间：2026-11-01。本表区分源码准备、云端证据和开发者发行权限；未勾选项不因 CI 绿色自动完成。当前工程是 iOS 17+ / Swift 6 / iPhone、iPad 和 Mac Catalyst 基线，不是原生 macOS target。

## 产品与功能

- [ ] 确认最终产品名、bundle identifier 的归属和商店定位。
- [ ] 接入并实际验证可发布的本地模型推理，包括加载失败、停止、内存和设备能力回退；模拟 runtime 或 placeholder 不算完成。
- [ ] 确认模型来源、许可证、再分发限制和所需用户同意；不自动下载权重，不默认开源本项目。
- [ ] 按[模型完整性合同](model-integrity.md)核对根文件类型、权重摘要与独立外置 tokenizer 摘要；GGUF 必须明确使用内嵌词表，不把 staged 当成 verified。
- [ ] 商店文案、截图和预览仅描述已实现能力，不把模拟指标当作实测，不加入图片/语音/漫画翻译等非目标功能。

## 隐私与用户帮助

- [ ] 核对本轮“关于、隐私与帮助”入口及生产界面的亮暗主题、大字、真实呈现和辅助访问证据；新增公开手机 UI 测试拟覆盖普通/AX5 的打开、七组正文滚动、关闭和草稿返回，原六项/22图保留并增至八项/26图，实际云端结果核对前不记通过。
- [ ] 开发者提供并验证公开隐私政策、支持网址和真实联系信息；源码 Markdown 与私有仓库链接不自动满足商店 URL 要求。
- [ ] 核对 App Store 隐私标签与实际二进制、系统备份、照片选择、导出和剪贴板边界一致：会话（含修复原件）与托管模型目录排除备份，壁纸/外观 AppStorage 仍可能备份，卸载会失去未导出的对话。
- [ ] 根据实际发布版 API/依赖重新审核 `PrivacyInfo.xcprivacy`；不以历史 manifest 作为未来新增 runtime 或 SDK 的自动批准。
- [ ] 核对会话/修复原件/新导入模型备份排除与失败传播的云端测试；旧模型目录扫描迁移为 best-effort，系统拒绝时不保证排除。评估临时导出、壁纸/外观、既有系统备份的容量与用户删除路径，不声称所有数据绝不离设备。

## 云端验证与证据

- [ ] 绑定候选代码完整 SHA、分支、run/attempt，核对全部所选必选阶段，不能用旧包或部分成功替代。
- [ ] 核对 iOS / Catalyst / unsigned Release 构建、完整 XCTest、真实手机交互及发布资源检查。
- [ ] 下载对应完整结果包，独立核对 API digest、ZIP CRC、安全路径、manifest、JUnit、原始 xcresult 和截图，并实际看图。
- [ ] 真机验证模型推理、辅助技术、前后台/中断/终止、磁盘满、故障恢复、性能和热状态；Simulator 与宿主渲染不代替真机。
- [ ] 记录未覆盖的平台能力和故障耐久风险；不删除失败断言、skip 或降低门槛获取绿色。

## 发行权限与签名

- [ ] 开发者确认 Apple Developer 团队、App Store Connect App 记录和 bundle identifier 权限。工程里的团队标识不代表云端具备凭据。
- [ ] 将所需发行凭据安全配置到云端 secret，不提交证书、私钥、描述文件或密码到源码。
- [ ] 确认正式版本号与单调递增 build number。当前工程静态值 `1.0` / `1` 不代表已获得可上传构建号。
- [ ] 云端执行签名 archive/export，核对 entitlement、provisioning、签名、分发渠道和产物摘要；未签名 `.app.zip` 不能安装分发或视为上架包。
- [ ] TestFlight 安装与升级、真实设备回归、外部测试/商店审核信息、年龄分级和出口合规由实际发布内容决定并完成确认。
- [ ] 明确批准外部测试或正式提交前，不自动上传或发布。

## 当前边界

本仓库已有 unsigned iPhoneOS Release 资源检查与云端完整/手机交互工作流，并新增仅手动触发的[未签名归档入口](archive.md)；这不等于已完成签名发行、App Store 审核、真实模型推理或真机验收。本轮结果应由主任务按实际 SHA/run 记录，不在本清单预写通过。
