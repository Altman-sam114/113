# 本地推理失败后的重试

生产native请求失败后，聊天错误下方提供至少44pt的“在新会话重试”。它复用失败前的完整有序上下文和最后一个问题，在新会话开始一次真实请求；原会话中的问题、部分回答、错误原文和未发送草稿保留，可从历史重新选择。错误原文已经进入消息记录时，输入区仅显示短状态与重试按钮，避免大字下重复长错误挤占输入空间。不把失败的部分回答加入重试上下文，也不在新会话重复插入user消息。

该动作只适用于当前内存中、当前会话的一次native失败。当前选中模型的身份、manifest和context必须匹配，artifact仍须verified，runtime仍支持该模型；实际执行使用当前artifact目录重新进入完整文件身份/SHA校验，不沿用旧文件句柄或跳过verified。双击、生成中、恢复/修复中、缺目录或未verified均不创建新会话。新发送、换会话/模型、reset、文件失去verified会清除旧重试。App重启不持久化请求或自动重试。

新会话后仍使用原generation/session identity、串行native worker和停止/错误路由；再次失败可以再次明确重试，成功则结束重试资格。没有模拟回答兜底、模型下载、网络推理或自动执行外部操作。它改善失败恢复，不改变[已记录的270M质量失败](https://github.com/Altman-sam114/113/actions/runs/42340772593)。
