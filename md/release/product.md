# AgentX：本地大模型对话范围

调研日期：2026-11-01。视觉参考只读的 AITRANS；功能以本地大模型聊天为中心，不复制图片翻译、语音翻译、漫画或订阅占位模块。

## 一手资料

- [PocketPal AI 官方项目](https://github.com/a-ghorbani/pocketpal-ai)：离线 GGUF 对话、模型导入、流式生成、停止、重新生成、编辑消息、个性助手与设备基准。其联网搜索、模型社区和语音是可选能力，不代表本项目应引入这些网络路径。
- [LLMFarm 官方项目](https://github.com/guinmoon/LLMFarm)：本地模型加载、Metal、采样参数、模型配置模板、上下文恢复及可选 RAG。README 同时说明其当前商店可用性限制，不能据此推断本项目已满足发行条件。
- [MLC-LLM iOS 官方文档](https://llm.mlc.ai/docs/deploy/ios.html)：设备端编译、模型库与运行部署边界；仅有 UI 或文件不是完整推理实现。

## 发布首要能力

| 优先级 | 能力 | 当前事实 / 验收要求 |
| --- | --- | --- |
| P0 | 真实离线文本推理 | 当前仍为模拟。需要真实 tokenizer、chat template、模型执行与流式事件；不得把占位输出标为 REAL。 |
| P0 | 安全模型导入 | 保留用户 Files 原件、可信 SHA-256、事务替换、失败/取消不破坏旧代；目录哈希必须覆盖文件边界和隐藏项。GGUF 不应强制外置 tokenizer。 |
| P0 | 多轮上下文 | 请求须携带有序 system/user/assistant 历史，按真实 tokenizer 执行上下文预算，超限不能静默丢掉重要指令。当前同步请求仅携带本轮 prompt，不算已完成。 |
| P0 | 真实停止与错误恢复 | 加载、prefill、decode 可取消；native 完全停止后再释放/换模型，迟到 token 不得写入其他会话。现有模拟停止不能代替此验收。 |
| P0 | 本地会话与隐私 | 多会话、逐会话草稿、重启恢复、搜索、删除确认、复制和导出；损坏归档不能被初始空会话覆盖。会话不参与系统备份，需告知用户主动导出。 |
| P1 | 重新生成 / 编辑重发 | 保留原回答或明确分支/替换确认；不得为重试静默清空其他消息或当前草稿。接真实 runtime 后按同一 generation identity 路由。 |
| P1 | 角色与生成设置 | system prompt、最大输出、上下文长度、temperature/top-p 等只在后端实际支持时开放；参数需有界，不做无效装饰开关。 |
| P1 | 可读回答 | 完整文字、代码/Markdown、选择复制、大字、长回答滚动、键盘与多任务窗口适配；保持 44pt 以上动作。 |
| P1 | 实测状态 | 模型加载/内存不足/生成/停止/失败明确区分；速度、耗时和内存须来自实际测量，参考预算不能标为设备实测。 |
| P2 | 文档问答 / RAG、快捷指令、工具 | 真实文本聊天稳定后再评估。文档只在用户明确导入后本地处理；本轮不接搜索、云端 API、代理自动执行、语音或翻译模块。 |

## 实现顺序

先完成安全与诚实状态、AITRANS 视觉、帮助与云端交付基础；再以固定版本的纯文本 native runtime、串行 worker、真实 token 流、GGUF 单文件验证和多轮上下文贯通 P0。没有权重也可验证编译/链接、取消身份和畸形文件拒绝，但真实推理必须使用用户明确提供或授权的特定模型、可信哈希与许可证，不自动下载权重，也不提交或打进 CI 普通产物。

最终签名、真机 Metal/内存/热状态、辅助技术、故障耐久、公开隐私与支持网址、TestFlight 和商店审核仍按[发布检查表](checklist.md)逐项验收。此范围不是完成声明。
