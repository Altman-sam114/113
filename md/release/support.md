# 使用帮助与反馈

## 本地大模型对话工作台

产品方向是本地大模型对话，不包括图片、语音或漫画翻译。当前默认是明确标识的模拟回复；模型导入和校验已存在，但不应把部署计划、`verified` 文件状态或模拟指标当作可运行的真实推理。

- 对话：输入后发送，可停止生成、复制单条回复、导出当前对话。
- 任务模板：先填入输入框，再补充内容；模板不代表当前模拟 runtime 已具备相应智能能力。
- 会话记录：对话和逐会话草稿保存在本机，重启后恢复。会话目录（含修复原件）不参与系统备份；卸载 App 会失去未导出的对话。删除前需确认。
- 模型：手动从 Files 导入，文件在本机复制、校验和卸载；新导入目录设置排除备份标记失败时会报错，旧托管目录扫描尝试迁移但系统拒绝时不能保证排除。不自动下载权重，用户需确认来源与模型许可，并自行保留 Files 原件。
- 设置：外观、自定义壁纸和本地运行策略。“关于、隐私与帮助”可离线查看当前能力、隐私边界及真实 App 版本/构建号。

## 常见问题

### 回复为什么不对应输入？

默认是模拟回复，用于验证逐字输出、停止、复制和会话流程。它不是实际模型回答，不能用于检验真实模型质量。

### 导入文件通过校验，为什么仍不是实际推理？

文件存在、格式和 SHA-256 校验与 runtime 集成是不同步骤。`manual-import-required` 不是真实可运行权重；`verified` 也不意味着真实推理已经实现。

### 会话无法保存或恢复怎么办？

写入失败可通过界面“重试”；读取失败先保留原件，不要反复覆盖。明确选择“保留原件并修复”会保留原始文件后重建记录，不承诺修复文件中的全部内容。修复备份仍保存在 App 目录内。

### 如何移除内容？

会话记录中删除并确认；模型页卸载并确认；设置中恢复系统背景。会话（含修复原件）与托管模型按上述策略排除系统备份，旧模型目录迁移存在例外；壁纸/外观偏好仍可能进入系统备份。卸载前请导出需要保留的对话。Files 原件、已导出的 Markdown、既有系统备份和其他 App 中的副本需分别管理。详细边界见 [隐私说明](privacy.md)。
